# Resin v1.4.0

## Platforms

- Platforms can select which subscriptions contribute nodes.
- An empty allowlist still accepts every subscription. Selected subscriptions are matched by ID and combined with existing tag regex and region filters.
- Deleting a subscription removes it from platform allowlists in the same database transaction. Retrying delete also clears leftover IDs.

## WebUI

- Platform create and edit include an allowed-subscriptions picker with name search.
